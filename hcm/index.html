Key Architecture & Engineering Highlights

🛡️ Database-Enforced Multi-Tenancy (PostgreSQL RLS)

Tenant isolation is enforced directly at the database engine level via PostgreSQL Row-Level Security (RLS) using SET LOCAL app.current_tenant_id = '...' on transactions, guaranteeing zero cross-tenant data leaks even in shared multi-tenant tables.

⚡ Path-Based Strict Routing (/{slug}/...)

Eliminates domain/subdomain DNS fragility by scoping all tenant requests cleanly through path-based routing (e.g. /aensoft/dashboard, /acme/hr/positions). Seamlessly resolves tenant contexts with zero proxy configuration overhead.

🔐 Dynamic Permission-Based Access Control (PBAC)

Fully decoupled from hardcoded roles. Routes are dynamically evaluated against a centralized permission catalog (HTTP method + resource path matching), allowing tenant administrators to create unlimited bespoke roles.

🚀 Serverless Connection Efficiency & Scale-to-Zero

Optimized for serverless cloud databases (Neon Serverless PostgreSQL) with tuned HikariCP connection lifecycles, lazy initialization timeouts, and idle connection releasing to enable cost-effective autoscaling.

🧪 Automated Playwright Java E2E Test Suite

End-to-end integration tests written with Microsoft Playwright for Java and JUnit 5, testing complete cross-portal lifecycles from tenant onboarding to candidate hiring with automated full-page screenshot and video evidence generation.

🔄 Schema Migrations via Standalone Flyway Module

Centralized database version control with explicit Maven profile execution (-P genesis, -P talent, -P career) and centralized schema histories within a dedicated flyway schema.
